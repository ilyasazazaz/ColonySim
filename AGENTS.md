# Инструкции агентам ColonySim

Перед нетривиальной работой прочитайте:

1. [AI/CONTEXT.md](AI/CONTEXT.md) — действующие решения и границы перезапуска.
2. [AI/WORKFLOW.md](AI/WORKFLOW.md) — инструкции ролей, разметка, согласование и Git.
3. [AI/STATUS.md](AI/STATUS.md) — текущий этап и нерешённые вопросы.

## Приоритеты

- Рабочий язык — русский.
- Сейчас создаётся карта проекта в Obsidian. Не начинать разработку или подготовку подробного ТЗ без поручения.
- Прежние технические утверждения не считать действующими решениями только потому, что они сохранились в заметках, коде, истории Git или старых обсуждениях.
- Авторский текст сырья неприкосновенен; разрешены служебные якоря по WORKFLOW.md. Исправления и прочие служебные данные находятся в производных заметках.
- Не плодить файлы промптов, журналов и вариантов текста. Роли определены в одном WORKFLOW.md.
- Агент не согласовывает собственную работу от имени человека и не утверждает проектные идеи.
- При назначении роли следовать её инструкции; без назначения работать как мастер-агент над процессом и обсуждением. Не запускать остальных агентов автоматически.

## Источники и проверка

- ObsidianVault/ — первоисточники и их производные; статус решения должен быть явным.
- AI/ — действующие служебные правила и компактный контекст, без копирования продуктовых заметок.
- Product/ — существующие материалы продукта, вне текущей задачи по умолчанию.
- GitHub — обсуждения и проверка изменений; старое обсуждение не подменяет новый выбор владельца.

Каждая задача ведётся в отдельной ветке и Pull Request. Не отправлять изменения прямо в main, не перезаписывать чужую работу, не сливать PR без поручения. Перед завершением проверить diff, ссылки и сохранность исходников. Не включать секреты, кэши и личное состояние редакторов.
