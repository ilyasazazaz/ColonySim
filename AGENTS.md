# Инструкции агентам ColonySim

Перед нетривиальной работой прочитайте:

1. `AI/CONTEXT.md` — подтверждённый контекст проекта.
2. `AI/WORKFLOW.md` — Git-процесс, правила координации и критерии готовности.
3. `AI/STATUS.md` — текущий этап и ближайшие задачи.
4. `AI/OWNER_MEMORY.md` — выводы из личной редактуры и подтверждений владельца.
5. `AI/ENGINEERING_MEMORY.md` — критические инженерные эвристики, критерии выбора инструментов и границы их применимости.

## Источники истины

- `ObsidianVault/` — требования, игровой дизайн, сеттинг и исследования.
- `Product/` — файлы создаваемого продукта и исполняемый код.
- `AI/` — инструкции и компактный межсессионный контекст для агентов.
- GitHub Issues и Pull Requests — задачи, обсуждение изменений и оперативный статус работы.

Не переносите одно и то же содержание между разделами без необходимости. Ссылайтесь на канонический документ.

## Общие правила

- Рабочий язык проекта — русский; имена программных сущностей и технические термины могут быть английскими.
- Не превращайте идеи из заметок в утверждённые требования без явного решения владельца проекта.
- Для каждой задачи используйте отдельную ветку и Pull Request. Не отправляйте изменения прямо в `main`.
- Не перезаписывайте чужие незакоммиченные изменения. Несколько агентов должны работать в отдельных ветках или worktree.
- Перед завершением проверьте diff, ссылки, структуру файлов и применимые тесты.
- Существенные изменения архитектуры или процесса фиксируйте в документации одновременно с реализацией.
- Заметку с тегом `источник` считайте прямым материалом владельца. Для тегов `редактировано` и `подтверждено` изучите Git-diff и историю; устойчивые выводы сохраните в `AI/OWNER_MEMORY.md`.

## Code Review Rules

- Отмечайте противоречия между реализацией, `AI/CONTEXT.md` и утверждёнными материалами Obsidian.
- Не допускайте попадания в Git сгенерированных файлов Unity, секретов, локальных кэшей и персонального состояния редакторов.
- Проверяйте, что изменение уровня симуляции не создаёт недетерминированную потерю уже подтверждённых игровых фактов.
