# Инструкции агентам ColonySim

Перед нетривиальной работой прочитайте:

1. [AI/CONTEXT.md](AI/CONTEXT.md) — действующие решения и границы перезапуска.
2. [AI/WORKFLOW.md](AI/WORKFLOW.md) — инструкции ролей, разметка, согласование и Git.
3. [AI/STATUS.md](AI/STATUS.md) — текущий этап и нерешённые вопросы.

## Приоритеты

- Рабочий язык — русский.
- Сейчас создаётся карта проекта в Obsidian. Не начинать разработку или подготовку подробного ТЗ без поручения.
- Прежние технические утверждения не считать действующими решениями только потому, что они сохранились в заметках, коде, истории Git или старых обсуждениях.
- Авторский текст сырья неприкосновенен; разрешены служебные якоря по WORKFLOW.md. Исправления и прочие служебные данные находятся в производных заметках.
- Не плодить файлы промптов, журналов и вариантов текста. Роли определены в одном WORKFLOW.md.
- Агент не согласовывает собственную работу от имени человека и не утверждает проектные идеи.
- При назначении роли следовать её инструкции; без назначения работать как мастер-агент над процессом и обсуждением. Для назначенных ролей разрешена цепочка передачи Агент 1 → Агент 2 → Агент 3 по WORKFLOW.md; других агентов автоматически не запускать.
- Мастер-агент редактирует только AGENTS.md и служебные документы AI/. Vault читает для анализа; не исправляет заметки, не добавляет в них якоря, не устанавливает плагины и не пишет реализацию кнопок. Критика результата — поручение обновить правила исполнителей, а не выполнить их работу. Расширение роли требует отдельного явного поручения владельца.

## Источники и проверка

- ObsidianVault/ — первоисточники и их производные; статус решения должен быть явным.
- AI/ — действующие служебные правила и компактный контекст, без копирования продуктовых заметок.
- Product/ — существующие материалы продукта, вне текущей задачи по умолчанию.
- GitHub — обсуждения и проверка изменений; старое обсуждение не подменяет новый выбор владельца.

Одна цепочка обработки ведётся всеми ролями в общей ветке и одном PR. Продолжать существующую ветку workflow без повторного вопроса о commit/push: владелец разрешил отправку результатов этапов. Не создавать новую ветку на каждый уровень. Параллельно редактировать разные файлы; запись в один файл и Git-операции выполнять по очереди с проверкой свежести. Слияние — только по решению владельца. Подробности и новые правила ссылок/разбиения — в AI/WORKFLOW.md. Не включать секреты, кэши и личное состояние редакторов.

Команда «работай» запускает полный проход уровня и проверку всех его производных по актуальным правилам. Сохранение авторских заголовков и абзацев в корректуре разрешено; это не работа Агента 2. Полноту подтверждать сверкой входа и выхода, не обещанием. Подробности, обработка реальных отказов и адресаты передачи — в AI/WORKFLOW.md.

Не завершать поручение обещанием работы. Файл-оболочка со встраиванием исходника не является корректурой. Готовность этапа подтверждать проверкой содержания каждого результата, а не количеством файлов; неверный сигнал готовности отзывать.

При новом назначении Агента 1 использовать пошаговый раздел его роли в WORKFLOW.md. Старый чат Агента 1 выведен из маршрута; новому исполнителю не наследовать его обещания готовности. Назначение роли и команда работы разрешают выполнение в том же ходе, без отдельного подтверждения ознакомления.
