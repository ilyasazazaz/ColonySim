# Product

Здесь находятся файлы создаваемого продукта, а не описание его замысла.

Содержимое:

- `ColonySim/` — созданный владельцем проект Unity 6000.5.9f1 на шаблоне Universal 2D;
- исходный код доменной симуляции и тесты;
- инструменты импорта, генерации и профилирования;
- исходные производственные материалы, необходимые для сборки продукта.

Первая архитектурная проба выполняется в `Product/ColonySim/`. Сейчас там находятся исходные файлы шаблона, настройки проекта и пакеты; генерируемые `Library`, `Logs`, `UserSettings` и аналогичные каталоги остаются локальными и игнорируются Git. Границы и критерии результата заданы в [`AI/ARCHITECTURE_BRIEF.md`](../AI/ARCHITECTURE_BRIEF.md). Код этой пробы является экспериментом: он не превращает весь Obsidian-граф в утверждённую архитектуру.

Требования, игровой дизайн и сеттинг остаются в `ObsidianVault/`. Большие бинарные ресурсы перед добавлением следует оценивать для хранения через Git LFS.
