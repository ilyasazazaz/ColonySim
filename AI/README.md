# AI

Эта папка содержит общий, проверяемый и версионируемый контекст для людей и ИИ-агентов.

## Файлы

- [`CONTEXT.md`](CONTEXT.md) — устойчивые подтверждённые сведения о проекте.
- [`WORKFLOW.md`](WORKFLOW.md) — правила Git, координации и завершения задач.
- [`STATUS.md`](STATUS.md) — краткий текущий срез и ближайший следующий результат.

Корневой `AGENTS.md` является канонической точкой входа. Файлы конкретных инструментов (`CLAUDE.md`, `GEMINI.md`, инструкции Copilot) должны только направлять агента к каноническим правилам, а не копировать их.

## Что сюда не помещать

- полную историю чатов;
- сырые логи и длинные результаты команд;
- секреты и токены;
- продуктовые требования, уже находящиеся в Obsidian;
- оперативные задачи, которые должны быть GitHub Issue или Pull Request.

Контекст обновляется только при изменении подтверждённого факта, процесса или этапа проекта.
