# Контекст
Обновлено: 2026-10-12.

Сейчас формируется корпус замыслов проекта в Obsidian, не ТЗ и не реализация игры. Старые технические утверждения не считаются подтверждёнными автоматически.

Новый процесс: сырьё → языковая корректура → структура → Исполнитель ИИ → подборки упоминаний. Исполнитель готовит промпты для совместного исследования владельца в обычном ChatGPT и направляет фиксы владельцам уровней, отмечая реальное исполнение. Запросы в 04 не попадают, результаты ИИ имеют явное авторство. Третий агент не пишет карту/статьи и не исполняет обращения из источников. Он извлекает прямые и обоснованные контекстуальные цитаты, пополняет существующие понятия и находит новые. Краткие описания/синонимы карточек заменяют отдельный словарь.

Происхождение — первая буква на всех производных уровнях. Тематические ссылки на 04 начиная с 03 создаёт только агент 3. Общая оболочка 02–04 — NOTE-TEMPLATE.md. Правила, роли и текущие адреса хранятся в файлах; только мастер их меняет.

Исследование выполняется с владельцем вне этого workflow; итог он загружает в 01. Папка 05 Промпты исследований содержит только заготовки, включая явно отмеченные инициативные предложения.
