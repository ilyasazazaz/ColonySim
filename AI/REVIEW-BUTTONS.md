# Контракт общих кнопок
Оболочка и точный вызов JS Engine находятся только в [NOTE-TEMPLATE.md](NOTE-TEMPLATE.md). Не поддерживать второй шаблон в этом документе.

## Ответственность
Мастер поддерживает AI/review-buttons.js, тесты и побайтово синхронную копию ObsidianVault/90 Служебное/review-buttons.js, общий CSS и настройки. Исполнители устанавливают панель в свои заметки по шаблону, не меняют общий код/зависимости. Дефекты — мастеру. Нужен JS Engine; Meta Bind для этой панели не требуется.
Текущий JS допускает пути 02 Корректура, 03 Структура, 04 База знаний. Смысл 04 изменён на упоминания, физическое имя пока сохранено. Не переименовывать каталог без согласованной миграции проверок JS и ссылок.

## Четыре действия
- «Согласовать»: сохраняет человеческий статус, дату и хеш текущего текста.
- «Исправлено мной»: дополнительно фиксирует проверенные agent_revision/path в review_base_commit/path; это база для анализа мастером, не последний случайный коммит ветки.
- «Нужны правки»: меняет статус и создаёт/открывает один блок «Для ИИ». Сохраняет дату прежнего согласования. Никаких автоматических сообщений.
- «Отменить действие»: восстанавливает предыдущее состояние проверки, сохраняя текст, комментарий и историю событий. review_undo — служебная JSON-строка; отмена одношаговая, действует после повторного открытия. Если состояние вручную изменено после клика, не перезаписывать его.

Повторный клик по той же редакции не плодит события. Открытие панели ничего не записывает. Обрабатывается заметка, содержащая панель, не случайная активная вкладка. Конкурентная запись отменяет операцию без потери правок. Время событий — UTC с Z.
review-v3 — формат reviewed_revision, не автоматическая миграция source_revision. Исключает YAML и явно размеченные служебные блоки; нормализует пробелы прозы, технические якоря и представление ссылок. Код сохраняет после нормализации переносов. Старый формат согласования не пересчитывать за человека. Цель ссылки проверяется отдельно: изменение цели при том же видимом тексте не меняет хеш текста.
Существующий неразмеченный «Для ИИ» исполнитель обрамляет маркерами, сохраняя текст. Не создавать дубликат. Все поля review_* и decision_status сохраняются при изменениях оболочки.

## Проверки
node AI/review-buttons.test.cjs — изолированные проверки логики, не UI. После изменения общего JS мастер сравнивает SHA256 исходника и vault-копии.
Проверка интерфейса — только на временной заметке: четыре действия, дата, история, повторный клик, изменение текста, отмена без потери комментария, правильный целевой файл, повторное открытие. Реальные материалы не согласовывать тестовыми кликами.
Недоступный интерфейс обозначить честно; не выдавать тесты кода за проверку UI и не блокировать независимую текстовую обработку.
