# ColonySim

Мобильный colony simulator с масштабируемой глубиной симуляции.

## Структура репозитория

- [`ObsidianVault/`](ObsidianVault/) — база знаний, требования, дизайн и исследовательские заметки. Папку можно открыть в Obsidian как самостоятельный vault.
- [`Product/`](Product/) — создаваемый продукт: Unity-проект, исходники, тесты, инструменты и производственные материалы.
- [`AI/`](AI/) — общий контекст, правила работы и состояние проекта для людей и ИИ-агентов.

Служебные файлы в корне нужны GitHub и агентам. Каноническая инструкция для агентов — [`AGENTS.md`](AGENTS.md).

## Текущее состояние

Проект находится на стадии формализации концепции и подготовки технического задания. Актуальный срез состояния хранится в [`AI/STATUS.md`](AI/STATUS.md).
