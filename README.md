# ColonySim

Проект находится на этапе построения карты идей и концепций в Obsidian. Прежний подход к формализации и разработке пересматривается владельцем.

- [ObsidianVault/](ObsidianVault/) — первоисточники, корректура, структурированные записи и база знаний.
- [AI/](AI/) — актуальный контекст, инструкции ролей и состояние процесса.
- [Product/](Product/) — существующие материалы продукта; их наличие не утверждает будущую архитектуру.

Инструкции агентов: [AGENTS.md](AGENTS.md). Состояние и ограничения: [AI/STATUS.md](AI/STATUS.md). Правила уровней и человеческого согласования: [AI/WORKFLOW.md](AI/WORKFLOW.md).
