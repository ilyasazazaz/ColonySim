[[03 Структура/2026-09-27 — Подход к проекту и обработке заметок#^s-009|Третий]] агент распределяет идеи структурированной записи по тематическим файлам, связывает их и создаёт навигацию. Один входной документ может породить несколько самостоятельных заметок.

[[03 Структура/2026-09-27 — Подход к проекту и обработке заметок#^clar-007|Агент]] также работает с поручениями, адресованными ИИ. Исторические команды из сохранённой записи не являются повторным поручением запускать работу.

Практическое уточнение владельца от 2026-10-02: отдельные темы получают отдельные файлы; для данного материала нужны заметки по каждому агенту. Агент самостоятельно подбирает тематические теги, не дублируя ими статусы согласования. Основание: текущая обратная связь владельца; это дополнение мастер-агента, а не цитата из предыдущего слоя.
