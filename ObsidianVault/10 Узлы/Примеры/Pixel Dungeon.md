Pixel Dungeon полезен как понятный пример локального подземелья: уровень состоит из [[Комната|комнат]], проходов и специальных областей, а этажи образуют последовательность исследования. Игроку показывается конкретная двумерная карта, хотя её структура создаётся процедурно.

## Что можно извлечь для графа

Абстрактный план этажа можно сначала представить связями обязательных комнат, затем разместить комнаты на сетке и соединить [[Коридор|коридорами]]. Лестницы закрепляют связь между слоями. После исследования форма уровня становится фактом, а ещё не созданные этажи могут оставаться кратким описанием или seed.

Пример удобен для первого испытания преобразователя пространства: задача ограничена, результат видим, а инварианты достижимости легко проверить. При этом Pixel Dungeon сам по себе не демонстрирует смену представлений одного живого мира.

## Что было упущено в первом разборе

Pixel Dungeon использует [[Пошаговое время|пошаговое время]]: действие героя продвигает остальных участников, что позволяет сложному решению занимать сколько угодно реального времени. Инвентарь, экипировка, расходуемые [[Ресурс|ресурсы]], голод, эффекты и развитие героя связывают исследование с постоянным выбором риска.

Исходный код игры открыт. Это делает пример удобным для изучения границ классов уровня, акторов, [[Предмет|предметов]] и очереди действий, но его структура не обязана быть образцом для масштабируемой симуляции.

- соединяет их через → [[Коридор]]
- связывает уровни через → [[Переход между слоями]]
- использует → [[Процедурная генерация мира]]
- использует → [[Пошаговое время]]
- использует → [[Ограниченная информация]]
- использует → [[Предмет]]

## Выделенные версии систем

- [[Комнатный граф Pixel Dungeon]] превращает графовый замысел этажа в клеточную карту.
- [[Пошаговая очередь Pixel Dungeon]] определяет порядок и стоимость действий.
- [[Пошаговый бой Pixel Dungeon]] использует ту же очередь для перемещения и атаки.
